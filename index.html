Tentang

Cisco CCNA2026
MikroTik MTCNA2026

Saya bekerja di persimpangan jaringan fisik dan perangkat lunak — merancang topologi, mengamankan lalu lintas data, lalu menuliskan kode untuk mengotomatisasi semuanya.

Pengalaman saya dimulai dari lapangan: memasang dan memperbaiki jaringan CCTV serta perangkat IT klien, sebelum masuk ke dunia virtualisasi lewat proyek UKK Cloud Engineer menggunakan Proxmox VE.

Saat tidak sedang mengonfigurasi router, saya menulis kode kecil dengan JavaScript dan Bash untuk mempermudah pekerjaan infrastruktur sehari-hari.
